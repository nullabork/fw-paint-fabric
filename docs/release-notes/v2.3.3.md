# FW Paint v2.3.3

**New placement mode: Face target.** Paint only on blocks of the type you click.

Targets: Minecraft **26.3** · Fabric Loader **0.19.5+** · Fabric API for 26.3 (Fabric jar
only) · Java **25**.

## New

- **Face target** (wheel → Place → Blocks): like Face, but the selection only spreads across
  blocks of the same type as the one you click. Click a stone floor and only the stone gets the
  green preview and grows; grass, dirt or planks beside it are left alone. With a start marker
  behind the clicked column, the marker group decides the selection, as in Face any.

## Changed

- **Face is now labelled "Face any"** to tell it apart from Face target. It works the same, and
  if you had Face selected you still do.
