# FW Paint v2.0.0-beta.1

**The palette release (beta).** The Gradient and Noise Paint tabs are gone — in their place,
**Palettes**: named, saved block ramps you build once and reuse for both gradient *and* noise
painting. This is a beta of a fundamentally new model; the full design lives in
[`docs/v2-palette-spec.md`](../v2-palette-spec.md).

Targets (unchanged): Minecraft **26.2** · Fabric Loader **0.19.3+** · Fabric API for 26.2 (Fabric
jar only) · Java **25**.

## Palettes

- The new **Palette tab** lists every saved palette — name on the left, its segment sprites on the
  right, one row expandable into a full settings summary. **Use / Edit / Delete** (with
  confirmation) above the list; missing-block palettes get a red border and list exactly what's
  missing.
- The **palette editor**: preview up top (gradient cylinder ⇄ noise cube via the G/N toggle, ⛶
  expands), a colour-sorted source list on the left (double-click to add segments), the **segment
  strip** in the middle, and a slim settings column with (?) help popups. The page scrolls when it
  doesn't fit.
- The strip is the palette: drag stop handles to resize segments (Curve → Custom), drag segments
  up/down to reorder (Order → Custom; only the swapping pair moves), drag one sideways out to
  remove it, arrow keys / Delete work on the selected segment. Labels sit beside their segments,
  marquee-scroll when long, and pack together when segments get thin.
- **Automatic segments** — the crosshatch wildcards: *Automatic colour* / *Automatic brightness*
  resolve to real inventory blocks at paint time. At the strip's start they read the block you
  started on; at the end they scan to an end marker or the first solid block; in the middle they
  blend between neighbours. Right-click a block in the editor's list to ban it from Automatic
  picks (saved per palette).
- **Sizing modes** replace Max steps: **Min blocks** (shortest run that fits the ratios),
  **Fill space** (out to the end marker / first block), **Set steps** (fixed length).
- Palettes persist in their own `config/fw-paint-palettes.json`. Saving activates the palette;
  a new **cycle-palette keybind (default B)** steps through them in-game, and the HUD shows the
  active palette's sprites + name.

## Placement changes

- Gradient AND noise painting now consume the active palette (noise type/scale/seed live on the
  palette). Marker anchoring, single/face/3D, region fills, and gradient memory all still work —
  memory now also resets when you switch or edit palettes.
- Missing blocks: painting refuses (with a message) when a palette's blocks aren't all available;
  a new Settings toggle can **skip missing segments** instead. Blocks are drained from anywhere in
  the palette's source range (hotbar and inventory).
- 3D paints must end in a real block (Automatic-at-start is fine); clear errors otherwise.

## Retired (v1 → v2)

- The Gradient/Noise tabs, `[S]/[E]/✓/✗` assign buttons, required/excluded lists, Pick mode, the
  From: Markers toggle, Pixel %, and the top-%/diff gradient modes. Explicit segments + Automatic
  wildcards + the Order toggle cover these more directly.
- **No config migration**: v1 gradient settings are ignored. First run starts with no palettes and
  the mod guides you — the HUD points at the K screen, and with no tool assigned the screen opens
  straight on Settings.

## Beta notes

Please report anything odd in the editor interactions (drag-reorder, drag-out removal, stop
handles) and Automatic resolution choices — this is the release's riskiest ground.
