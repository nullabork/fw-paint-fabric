# FW Paint v2.3.2

**3D Fill grows around the block you click.** Small behaviour change on Minecraft 26.3.

Targets: Minecraft **26.3** · Fabric Loader **0.19.5+** · Fabric API for 26.3 (Fabric jar
only) · Java **25**.

## Changed

- **3D Fill is centred on the clicked block.** It used to start from the air block in front of
  the face you clicked. Now the block you click is the centre: the first shell wraps all of
  its open sides, and holding grows the sphere outward from it. The clicked block itself isn't
  painted. The placement preview already highlighted every open face of the target, and now
  that's exactly where the first shell goes.
- **3D gradients** start their first colour on the shell touching the clicked block. Fills have
  the same number of colour steps as before.
- Clicking a fill's centre block again continues that fill, like clicking any of its blocks.
