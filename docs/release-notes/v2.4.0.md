# FW Paint v2.4.0

**Marker line, and painting into open air.**

Targets: Minecraft **26.3** · Fabric Loader **0.19.5+** · Fabric API for 26.3 (Fabric jar
only) · Java **25**.

## New

- **Marker line** (wheel → Place → Shape markers): a free curve in 3D.
  - Click a start and an end on block faces (aim at the sky for a point 16 blocks out). Main
    nodes sit in the middle of block-grid cells, so straight lines are easy: new points,
    double-click-added nodes and released node drags all land on the grid.
  - Drag the nodes to move them. Pull the pink curve handles out of a node to bend the line;
    drag a handle back onto its node for a sharp corner.
  - A dragged point keeps its distance from you as you sweep the crosshair; walk around it to
    drag it another way. **Scroll while dragging** to push it further away or pull it nearer.
  - Two new rebindable modifiers. **Axis lock** (default **Alt**): while dragging a node,
    handle or the whole-line move node, lock it to the X, Y or Z axis it's mostly moving along;
    a coloured guide line shows the track. **Link** (default **Ctrl**): mirror the opposite
    curve handle (a smooth corner), make both tube ends the same size, or twist both ends
    together.
  - **Double-click** the line to add a node. Middle-click a middle
    node to remove it, anything else on the line to delete it.
- **Tubes along a line.** Floating buttons above the line sweep a **circle, square, triangle
  or star** along it, as a **Shell** (default) or **Solid**. The glowing blocks show exactly
  what will be painted, tight bends included. Each end gets a **size node** (different sizes
  make a taper, e.g. a tentacle) and a **twist node**; a node beside the line moves the whole
  thing. A bare line selects just the blocks it passes through.
- Lines weave through the world but also show **faintly through terrain** (line, nodes, handles
  and the tube's edges), and their nodes and handles can be grabbed through blocks.
- **3D Fill aimed into a tube fills the whole tube** at once, with Solid, Gradient or Noise.
  Gradients run from the line's start to its end.
- **Place in air** (Settings, on by default): blocks with nothing next to them are placed
  straight into the air, so fills and tubes in open sky need no scaffolding. Turn it off on
  servers whose anti-cheat flags that; blocks then wait for a neighbour as before.
