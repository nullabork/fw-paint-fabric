# FW Paint v2.4.1

**Don't match palette, wheel descriptions, and hanging roots left alone.**

Targets: Minecraft **26.3** · Fabric Loader **0.19.5+** · Fabric API for 26.3 (Fabric jar
only) · Java **25**.

## New

- **Don't match palette** (wheel → Place → Settings): a toggle that stops Face any, Face target
  and Face perp from spreading onto blocks of your current selection — the palette's blocks
  (Gradient, Noise), the pattern's blocks (Pattern) or the selected Solid block. Lay one layer,
  click beside it, and the selection stops at the layer instead of growing over it. The block
  you click still counts. While it's on, the wheel slot is lit and the HUD shows a yellow
  reminder. It isn't saved: it's off again after a restart.
- **Wheel descriptions.** Hovering any wheel item shows a short description along the bottom of
  the screen.
- The Place ring has a new **Settings** item, which opens a third ring of quick toggles.

## Fixed

- **Hanging roots, grass, vines and other plants vanilla lets you place into are now kept.**
  The selector used to show the cell next to a hanging root while the click actually replaced
  the root. Those plants now count as solid for painting (only air and fluids are empty), and
  are never used to place against.
