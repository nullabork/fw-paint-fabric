# FW Paint v3.0.2

**Re-aim a line's rotate rings.**

Targets: Minecraft **26.3** · Fabric Loader **0.19.5+** · Fabric API for 26.3 (Fabric jar
only) · Java **25**.

Your palettes, patterns, markers and settings carry over.

## New

- **Tilt a rotate ring.** In a line's rotate mode, hold Axis lock (default **L-Alt**) and drag a
  ring: that ring alone leans about the other ring's axis, and the line stays where it is. A
  plain drag afterwards turns the line about the new direction, so a line can be turned about
  any axis, not just the two it started with.
  - Alt is read when you grab, so letting go of it mid-drag does not switch to a turn.
  - The action bar shows the tilt angle. The Modifier (default **L-Ctrl**) gives 15° steps.
  - The tilted rings are saved with the line.

## Known limits

- There is no one-click way to put tilted rings back to straight; tilt them back by hand
  (15° steps help).
