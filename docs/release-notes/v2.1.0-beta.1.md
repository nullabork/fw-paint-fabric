# FW Paint v2.1.0-beta.1

**Patterns + Face Perpendicular.** Draw a 2D block grid by hand and paint it as a plane — plus a
new 1-block-wide placement mode with 45° diagonals. Design doc:
[`docs/v2.1-patterns-spec.md`](../v2.1-patterns-spec.md).

Targets (unchanged): Minecraft **26.2** · Fabric Loader **0.19.3+** · Fabric API for 26.2 (Fabric
jar only) · Java **25**.

## Patterns

- **A second kind of palette item**: press **+ Pattern** on the Palette tab to open the pattern
  editor — pick a block (its sprite rides your cursor), hold left-click to draw it into a grid
  up to **32×32**; pressing a cell that already holds your block turns the drag into an eraser
  for that block only. Width/Height inputs resize the canvas (cropped cells survive until you
  save); empty cells are **holes** that place nothing; an iso preview shows the pattern as a
  wall.
- **Pattern is its own paint type** — V now cycles Gradient → Noise → Solid → Pattern, and the
  cycle keybind (B) steps through *patterns* while Pattern paint is active and *gradients*
  otherwise; each kind keeps its own active selection, HUD row, and Paint-tab display.
- **Placement**: the pattern starts at its **start** edge and advances out of the clicked face;
  its width runs across a plane derived from your facing, snapped to 45°/90°. Painting a box
  yields the pattern on the plane-parallel faces and edge streaks on the perpendicular sides —
  and **adjacent strokes continue the drawing** (placed cells cache their position in the
  pattern) instead of restarting.
- **Tiling**: none / sides / start–end / both. **Variation (experimental)**: ±1–±3 — a cell may
  swap to a block that many positions away in the colour ordering of your inventory. No chaos —
  patterns place what you drew, and running out of a block stops with "out of X".

## Face Perpendicular

- A new placement mode between Face and 3D Fill: a **1-block-wide run** through the clicked
  block, along the direction you're looking **snapped to 45° or 90°** — diagonal stair-stepped
  runs included (up-diagonals across walls too).
- End markers stop it; with a start marker behind the click only the **marked blocks along the
  run** are selected, never the whole marker plane. Works with every paint type.
- The snapping is the new **Perp snap (45°/90°)** toggle in Settings, shared with the pattern
  plane.

## Everything else

- Palette list rows show pattern thumbnails and per-kind "in use" markers; Edit opens the right
  editor for the item's kind.
- The in-game Help gains Patterns and Face perpendicular topics.
- v2.0 palettes files load unchanged (items without a kind stay gradients).
