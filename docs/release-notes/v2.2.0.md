# FW Paint v2.2.0

**The selector wheel + region markers.** The cycle keybinds are replaced by a hold-to-open
radial selector wheel, and the marker system gains one-piece regions: a drag-out box plus
circle/square donut shapes with draggable controls — paint giant gradient cylinders and square
donuts with exactly the wall thickness you draw.

Targets (unchanged): Minecraft **26.2** · Fabric Loader **0.19.3+** · Fabric API for 26.2 (Fabric
jar only) · Java **25**.

## Selector wheel

- The old cycle keybinds (G for placement, V for paint type) are replaced by a **radial selector
  wheel**: **hold G** to open it (while holding the paint tool). The root ring has **Paint**,
  **Place**, and **Palette**; **hovering** a category fans its options into the next ring out
  (clicks are reserved for choosing) — Place fans Blocks / Markers / Shape markers, which fan a
  **third ring** of modes. The wedge **directly holding the current selection shows a blue
  tint**, the hole always shows the active paint type + mode, and every choice lands exactly
  like the old hotkeys did (persisted + action-bar flash) — set several in one hold, release G
  to close. The **FW Paint tab bar sits along the top of the wheel**: clicking a tab jumps
  straight into that settings page, which stays open after releasing G — the wheel doubles as
  a shortcut into the full screen. (There's no Disabled slot: the mod is only ever active
  while the paint tool is in hand.)
- The **Palette wedge follows the paint type**: your gradient palettes under Gradient/Noise,
  your patterns under Pattern — and under Solid it fans the **match modes** (Select block /
  Exact block / Closest colour / Closest brightness), with **Select block** fanning every
  unique placeable block in your source (hotbar/inventory) onto the next ring, Oklab
  colour-sorted like the list views and drawn as block icons (hover shows the name; clicking
  selects it as the Solid block).
- **Segments size themselves to their ring's content**: a ring of 16px block icons uses narrow
  slots, so dozens fit around the circle; how many fit before the ring becomes a scrolling
  **radial carousel** (a ‹ › arrow at each end, mouse-wheel scrollable, opening centered on the
  selection) follows from that — not a fixed cap. The whole wheel sizes itself from its labels
  once at open, so nothing ever overlaps or resizes live.
- Selections are remembered per paint type (and across sessions, as before) — and **missing
  things stay visible**: a selected Solid block no longer in your inventory keeps its slot
  (the carousel still opens on it) drawn red with a cross, and palettes/patterns with
  explicitly-defined blocks missing from their source show red with "(missing)".

## Region markers (box + shape markers)

- **Marker corners is replaced by Marker box**: two clicks mark the whole region as **one box
  marker** instead of filling it with columns of start/end markers — left-click the first
  corner (its face sets the gradient axis; that side is the START, tinted turquoise), then
  right-click the opposite corner (amber). One box at a time; a new one replaces it.
- **New Marker circle and Marker square modes**: donut ring regions built with three clicks —
  center (clicked face = plane; the base plane is the gradient start side), then two radii on
  that plane (they work over open air; equal = one-wide outline, apart = a band, i.e. the
  **wall thickness**). Rendered as one shape: culled-face fills with a bright merged silhouette
  that reads through water.
- **Control blocks** (live whenever the paint tool is in hand — just aim at one): drag the blue
  center to move, drag a blue radius to resize, drag a square's green corner nodes to **rotate
  freely** (jagged rasterized edges included). Right-click extrudes a layer along the normal
  (clear-connected modifier = the other way), and right-click **cancels a part-placed shape**.
- **Look at any part of a shape and its edges turn white** — it's then scrollable (slides
  along its axis; **Ctrl+scroll extrudes up / unextrudes down** a layer per notch),
  middle-click deletable, and editable via its controls. A **ghost outline shows through
  terrain**, so a shape moved underground stays findable and targetable, controls included.
  Multiple shapes allowed; everything persists per world+dimension.
- **Middle-click removes whatever marker you're aiming at** — a shape, the box, or a plain
  block marker — in any mode, tool in hand.
- Shape rendering is batched and cached (one draw submission per shape; the outline mesh
  rebuild that caused a hitch while rotating big shapes is now a balanced merge over a cached
  rasterization).
- **Regions restrict placement and set gradient direction**: painting that starts inside a
  region stays inside it (columns stop at the region edge like an end marker, 3D fills and the
  noise region fill respect it, Face mode inside a ring selects exactly the ring's faces), and
  gradients inside run from the region's start plane to its end plane — so an extruded circle
  paints as a **giant gradient cylinder** with exactly the drawn wall thickness.

## Everything else

- **Fluids count as empty space**: paint under water or lava — columns grow through liquid,
  fills flood it, scans and colour anchors see past it, auto end markers land on real terrain,
  and blocks place into it exactly like placing by hand (anything hand placement replaces —
  tall grass, snow layers — gets painted over too; waterlogged solids still count as solid).
- The **Paint quick-controls tab is retired** — the wheel does its job better. The FW Paint
  screen now opens where the paint type's selection lives: the Solid picker under Solid paint,
  the Palette tab otherwise.
- The keybinds move out of Misc into their own **FW Paint** category in Options → Controls
  (the wheel bind is simply "Quick selector"), and the in-game Help leads with a new
  **"How do I use this?"** 60-second topic (the CurseForge page opens the same way).
- The **Clear Markers** button counts and clears regions too; plain Marker and Marker draw are
  unchanged.
- The in-game Help's Getting started, Markers, and new Marker box / Shape markers topics cover
  all of the above, always showing your current keybinds.
- Old configs load cleanly: the retired Marker-corners placement mode falls back to Disabled,
  and the removed V/G cycle keybinds simply disappear from Controls.
